## &nbsp; 📌 &nbsp; Overview

<br/>

> **CurvBooks** is a full-stack book borrowing and discovery platform crafted for passionate readers.
> It unites a rich catalogue, community rankings, author spotlights, and curated deals — all within
> a refined, performance-first interface.

Built on the **Next.js App Router**, secured by **Better Auth**, and styled through the expressive combination of **HeroUI** and **DaisyUI** — every interaction on CurvBooks is fast, accessible, and beautifully designed.

## &nbsp; 🔐 &nbsp; Authentication

<br/>

CurvBooks uses **[Better Auth](https://better-auth.com)** — a modern, framework-native authentication library designed specifically for Next.js full-stack applications.

<br/>

```
  ┌─────────────────────────────────────────────────────────┐
  │                    BETTER AUTH FLOW                     │
  │                                                         │
  │   User  ──▶  Sign Up / Login  ──▶  Session Created      │
  │                                         │               │
  │                              Protected Routes ✓         │
  │                              Type-safe Helpers ✓        │
  │                              Server + Client Auth ✓     │
  └─────────────────────────────────────────────────────────┘
```

<br/>

- ✅ &nbsp; Email & password sign-up / sign-in
- ✅ &nbsp; Secure, persistent session management
- ✅ &nbsp; Type-safe auth helpers — client & server
- ✅ &nbsp; Route protection via Next.js middleware
